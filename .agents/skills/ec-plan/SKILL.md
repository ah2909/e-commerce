# ec-plan

Read [the project workflow](../../../docs/development-workflow.md), especially Reusable stage commands and section 1. Resolve the active task and select stage-only execution using the shared rules.

Clarify material gaps and prepare the plan, technical solution, and verification strategy in the task document. Preserve existing implementation and identify any prior approval/evidence invalidated by a revision.

Present the plan and stop. Do not implement, spawn reviewers, or run final verification. Plan approval on a later turn does not automatically start the build. Report pending gates and suggest `$ec-build` after approval.
